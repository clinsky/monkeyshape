## Develop

```sh
mshape gate
```

`mshape` installs once per machine: `curl -fsSL https://github.com/clinsky/monkeyshape/releases/latest/download/install.sh | sh`.
The Rust toolchain is pinned in `rust-toolchain.toml`, and rustup installs it on the first
cargo command.

Built with [monkeyshape](https://github.com/clinsky/monkeyshape): where it's going is in
[docs/roadmap.md](docs/roadmap.md), and how humans and agents work here is in
[AGENTS.md](AGENTS.md).
